# Contribuindo

Obrigado por contribuir com o LAB//ABERTO. Abra uma issue descrevendo o problema, a proposta e como reproduzi-lo antes de mudanças grandes.

1. Faça fork e crie uma branch de feature.
2. Use Node.js 20+ e rode npm ci.
3. Implemente alterações pequenas e independentes, com testes em node:test.
4. Execute npm run validate antes de abrir o PR.
5. Documente mudanças no README e no ROADMAP quando fizer sentido.

Não inclua imagens pessoais, metadados reais, tokens, credenciais ou dados de projetos privados nos testes, commits ou issues. Use fixtures sintéticas. Mantenha a aplicação sem telemetria e sem upload de imagens.

Ao enviar contribuições, você concorda com a distribuição sob a licença MIT do repositório.
