# Roadmap

## v1.0 · MVP

- [x] Interface responsiva e arrastar e soltar.
- [x] JPEG, PNG e WebP estáticos.
- [x] Identificação de categorias de metadados sem exibir valores.
- [x] Re-encode local com canvas e inspeção do resultado.
- [x] Limites de tamanho e dimensões; rejeição de animações.
- [x] Testes, documentação, licença MIT, Docker e GitHub Actions.

## Próximos incrementos (não implementados)

- [ ] Testes E2E em múltiplos navegadores.
- [ ] Exportação em lote para ZIP, sem bibliotecas externas remotas.
- [ ] Visualização lado a lado da imagem original e limpa.
- [ ] Cobertura adicional de chunks e metadados proprietários.
- [ ] Melhorias de acessibilidade e internacionalização.

Qualquer mudança que amplie o escopo de privacidade deve incluir testes e atualização das limitações documentadas.
